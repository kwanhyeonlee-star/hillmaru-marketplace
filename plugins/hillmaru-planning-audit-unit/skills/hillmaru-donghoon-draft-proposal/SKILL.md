# (주)동훈 그룹웨어 기안 초안 작성 + 발주서 자동완성

이 스킬은 이쿠키(구매·데이터 담당)가 사용한다. HILLMARU/동훈그룹 구매 업무에서 반복되는 두 종류의 기안(지출_구매, 대금 지급 요청)을 실제 회사 그룹웨어(Amaranth10)에 임시보관 상태로 만들어두는 것이 목적이다.

## 절대 규칙 (안전)

- **그룹웨어(a10.donghoon.com)는 사용자가 그 세션에서 명시적으로 "기안 작성해줘" 등으로 요청했을 때만 접근한다.** 폴더에 견적서/엑셀이 들어있는 것을 발견했다는 이유만으로, 또는 이전에 비슷한 작업을 했다는 이유만으로 먼저 나서서 그룹웨어에 들어가지 않는다. 요청이 없으면 폴더 내용만 확인하고 "기안 작성해드릴까요?"라고 먼저 물어본 뒤 답을 기다린다.
- **"상신" 버튼은 어떤 상황에서도 클릭하지 않는다.** 오직 **"보관"** 버튼까지만 진행한다. 최종 상신(결재 제출)은 항상 사용자(이관현 대표)가 직접 한다.
- 그룹웨어에 실제로 로그인/자격증명을 입력하지 않는다 — 이미 연결된 브라우저 세션(Claude in Chrome, a10.donghoon.com)이 로그인되어 있다는 전제로만 동작한다. 로그인이 안 되어 있으면 사용자에게 알리고 중단한다.
- 저장(보관) 전에 채워 넣은 금액·업체·수량 등 숫자는 반드시 최종적으로 사람이 다시 확인해야 함을 완료 보고 시 함께 안내한다.
- 발주서 자동완성(2단계)도 마찬가지로, 폴더에 발주서 양식이 추가된 것을 보더라도 사용자가 요청하기 전에는 먼저 실행하지 않는다.

## 트리거되는 폴더 이름 규칙

사용자가 작업 폴더(연결된 workspace)에 아래 이름 규칙으로 폴더를 만들어 자료를 넣어둔다.

| 폴더명 패턴 | 문서 유형 | 폴더 안에 들어있는 것 |
|---|---|---|
| `[날짜]_[사업장]_[부서/품목] 구매` | 지출_구매 기안 | 업체별 견적서 PDF (여러 개일 수 있음) → 이후 결재 보관 완료되면 선정 업체의 발주서 양식(xlsx) 추가 |
| `[날짜]_[사업장]_[부서/품목] 구매_인터넷 구매` | 지출_구매 기안 (인터넷 구매) | 견적서 대신, 구매할 품목 정보만 있음 → 웹서치로 시세/판매처 조사 필요 |
| `[날짜]_[사업장]_코스관리팀 비료/농약 구매` (다른 기안들과 동일한 `[날짜]_[사업장]_[부서/품목] 구매` 패턴, 부서/품목에 "코스관리팀 비료" 또는 "코스관리팀 농약" 등이 들어감) | 구매_코스 기안 (비료/농약 등 코스관리 자재) | 구매요청공문(PDF) + 견적비교 내역(Excel) + 견적서 모음(Zip) 3종 |
| `[날짜]_[사업장]_업장 소모품 구매_[N]월분` | 지출_구매 기안 - **업장 소모품 구매 (매월 반복되는 정기 건, 아래 "1-2." 참고)** | 견적 비교표 PDF(전체 품목 취합) + 업체별 견적서 PDF 2~3개 |
| `대금 지급 요청_[날짜]` | 대금 지급 요청 기안 | 대표님이 정리해둔 엑셀 파일 |

**지출_구매 vs 구매_코스 구별 방법**: 폴더명 패턴 자체는 `[날짜]_[사업장]_[부서/품목] 구매`로 동일하다. 폴더 안 파일 구성으로 구분한다 — 업체별 견적서 PDF가 낱개로 여러 개 들어있으면 **지출_구매**, "구매요청공문"(PDF 1개) + "견적비교 내역"(Excel 1개) + "견적서 모음"(Zip 1개)의 3종 조합이 들어있으면 **구매_코스**다. 부서/품목 자리에 "비료"·"농약"·"코스관리" 등의 단어가 있으면 구매_코스일 가능성이 높으니 우선 폴더 내용물로 재확인한다. 폴더명에 "업장 소모품 구매"가 들어있으면 지출_구매 중에서도 **매월 반복되는 정기 건**이므로 일반 지출_구매 규칙이 아니라 아래 "1-2. 업장 소모품 구매" 절을 따른다.

폴더 안의 파일 구성 상태를 보고 지금 할 일이 "기안 초안 작성"인지 "발주서 자동완성"인지 판단한다:
- 견적서(또는 인터넷 구매 품목 정보)만 있고 기안 초안이 아직 없다 → **기안 초안 작성** 단계 진행
- 이미 기안 초안을 작성해뒀고, 새로 발주서 양식(빈 xlsx)이 폴더에 추가됐다 → **발주서 자동완성** 단계 진행
- 구매_코스 기안은 발주서 자동완성 대상이 아니다(발주서 2단계는 지출_구매 기안 전용) — 구매_코스 폴더에 다른 파일이 추가되더라도 별도 요청이 없으면 발주서 작업을 시작하지 않는다.

**세부 표현 규칙 (2026-07-30, 2026-08-03 대표님이 직접 다듬은 최종본에서 확인된 규칙, 반드시 지킬 것):**

- **1. 목적**: 짧게 "[사업장] [부서명] [품목] 구매" 정도로만 쓴다. 모델명·용도("소모품 및 부품 교체용") 같은 부연설명은 붙이지 않는다. (예: `1. 목적 : 힐마루 포천 코스관리팀 장비 소모품 구매`)
- **2. 주요내용은 지출_구매 기안이면 항상 포함한다 — 코스관리팀 장비 부품 구매뿐 아니라 본사/일반 부서의 PC·비품 구매 같은 건에도 반드시 넣는다.** (2026-08-03 최초 초안에서 "장비 보유현황과 무관한 건이니 생략"으로 판단해 이 섹션을 통째로 뺐다가, 대표님이 최종본에서 되살려 넣은 사례가 있다 — 다음부터는 생략하지 말 것.) 내용을 채우는 방식은 구매 성격에 따라 다르다:
  - **장비/부품 교체성 구매**: 항목 뒤에 관련 장비의 **"[제조사 한글표기] [장비명] [장비코드/형식] [대수]대 보유"** 형식으로 괄호를 덧붙인다 (예: `1) 유압 휠터엘리먼트, 압축스프링 등 소모품 교체 (바로네스 5갱모아 LM551 10대 보유)`). 이 정보는 지어내지 말고 워크스페이스 폴더 최상위의 `[사업장] 장비 보유현황` 류 PDF에서 찾아서 쓴다(파일명은 사업장별로 다를 수 있음). 견적서의 부품 규격(예: LM551, R47AF)을 그 표의 "형식" 컬럼에서 찾아 장비명·제조사·대수를 조합한다. 제조사는 한글 표기(바로네스, 시바우라 등)로 바꿔 쓰되 확실하지 않으면 영문 그대로 쓰거나 사용자에게 확인한다.
  - **일반 비품/설비 구매(장비 보유현황과 무관한 건, 예: PC·모니터·사무용품)**: 참조문서로 추가한 구매요청서의 "지시/전달사항"이나 "구매목적" 문구를 근거로 구매가 필요한 배경·사유를 1~2개 항목으로 요약해 적는다 (예: `1) 현재 PC 노후화로 정상 문서 작성 불가 상황 발생`, `2) 기존 사용 모니터 노후화로 상황실 CCTV 관제 업무용 모니터 교체 필요`). 구매요청서에 없는 내용을 지어내지 않는다.
  - 이 문장에서는 띄어쓰기를 자연스럽게 하되(예: "유압 휠터엘리먼트"), 아래 금액 표의 제품명 셀은 **견적서에 적힌 표기를 그대로**(예: "유압휠터엘리먼트", 띄어쓰기 없이) 옮긴다 — 문장 표현과 표 안 품명 표기가 다를 수 있다는 점에 주의.
- **3. 금액 헤더의 VAT 표기와 계산 기준 (매우 중요, 항상 지킬 것)**: 금액 표와 총계는 **항상 "VAT 별도" 기준, 즉 공급가(세전) 금액으로 통일한다.** 업체 견적서가 VAT 포함가로 최종 금액을 제시했더라도(예: "부가세 포함 3,281,300원"), 그 값을 그대로 쓰지 말고 **1.1로 나눠 공급가로 역산**해서 표에 넣는다. 반대로 견적서가 이미 공급가/부가세를 별도로 명시했으면 그 공급가 숫자를 그대로 쓴다. 표 맨 아래 총계 행의 "비고" 셀에도 "VAT 별도"라고 명시한다. (2026-08-03 사례: 두경디케이 견적서가 VAT 포함 3,281,300원으로만 적혀 있었는데, 1.1로 나눈 공급가 2,983,000원을 비교 표에 사용했다.)
- **금액 표(품목표) 구성**:
  - 컬럼: 구분 | 제품명 | 수량 | 단가(원) | 총액 | 업체명 | 비고
  - 제품명 셀: 품명과 모델/규격 코드를 줄바꿈으로 구분해 2줄로 넣는다 (예: "카브레이터" 줄바꿈 "E57100086"). "R47AF" 같은 장비 모델명은 제품명 셀이 아니라 비고 셀에 넣는다.
  - 업체명 셀: 같은 업체가 여러 품목을 공급하면 해당 행들을 **세로로 셀 병합**해서 업체명을 한 번만 표시한다 (같은 값을 행마다 반복 입력하지 않는다).
  - 비고 셀: 그 품목이 쓰이는 장비의 "브랜드 모델명"을 영문으로 적는다 (예: "Baroness LM551", "Shibaura R47AF"). 같은 장비에 쓰이는 품목들은 업체명과 마찬가지로 세로 병합한다.
  - 셀 병합은 표 메뉴의 "셀 합치기"를 쓰거나, 표를 새로 만들 때부터 병합 구조를 고려해서 작성한다.
- **복수 견적(2곳 이상) 비교 시 — 비교 표와 첨부 규칙 (2026-08-03 확인, 반드시 지킬 것)**:

### 들여쓰기 규칙 (2026-07-31 대표님이 직접 다듬은 최종본에서 확인, 반드시 지킬 것)

### 1-2. 지출_구매 - 업장 소모품 구매 (매월 반복되는 정기 건)

**이 카테고리는 2026-08-03에 힐마루 포천 "업장 소모품 구매의 건_8월분" 기안을 실제로 작성·보관하고, 대표님이 최종 상신 전에 직접 다듬은 완성본을 대조해서 학습했다.** 폴더명은 `[날짜]_[사업장]_업장 소모품 구매_[N]월분` 패턴이고, 안에는 견적 비교표(전체 품목 취합) PDF 1개 + 업체별 견적서 PDF 2~3개가 들어있다. 매달 반복되는 문서이므로 **반드시 기결문서함에서 전월(前月)의 같은 시리즈 문서("업장 소모품 구매의 건_[전월]월분")를 찾아 열어, 그 문서의 구조·표·문구를 그대로 본뜬다** — 아래 규칙은 일반 지출_구매 템플릿과 다른 부분만 정리한 것이니, 이 절과 실제 전월 문서 두 가지를 함께 참고할 것.

**일반 지출_구매 기안과 다른 점 요약**: (1) "7. 예산항목"을 비워두거나 생략하지 않고 실제 숫자를 채운 두 개 섹션("7. 집행 금액 비교", "8. 예산항목")이 항상 있다. (2) 3.금액 표의 "구분"은 견적서·비교표에 적힌 세부 품목 카테고리(미화/세탁/락카 등)가 아니라, 예산 관리 카테고리(보통 "락카", "골프텔" 두 개)로 다시 묶어서 넣는다. (3) 5.지급일과 6.기타사항의 표현 방식이 다르다.

### 1) 복사할 기준 문서 찾기

1. 전자결재 > 결재수신함 > 기결문서로 이동
2. 검색창에 문서 종류에 맞는 키워드로 검색 (지출_구매 기안이면 "지출_구매", 대금 지급 요청이면 "대금 지급 요청")
3. 가장 최근 문서 하나를 기준 문서로 선택한다 (내용은 어차피 전부 새로 교체하므로, 결재선/수신참조가 정상적으로 채워진 최근 문서면 충분하다). **단, 결재라인 구성(특히 합의 줄 유무)이 대상 부서/사업장과 다를 수 있으니 그대로 복사만 하지 말고 아래 4-1) 결재라인 규칙에 맞게 항상 재확인·수정한다.**
4. 그 문서 행의 "새창열기" 아이콘을 클릭해 docID를 확인해야 하는데, 클릭으로 팝업이 안 뜨면 아래 "팝업 URL 알아내는 법"을 사용한다.

### 2) 팝업 URL 알아내는 법 (클릭이 막힐 때)

`mcp__claude-in-chrome__javascript_tool`로 아래와 같이 `window.open`을 임시로 가로채서 호출 인자를 기록한 다음, 같은 요소를 클릭하고, 기록된 URL을 읽는다.

```js
window.__capturedUrl = null;
const _open = window.open;
window.open = function(url, ...rest) { window.__capturedUrl = url; return _open.apply(window, [url, ...rest]); };
```

그 다음 "새창열기" 아이콘(또는 문서 행)을 클릭하고, `window.__capturedUrl` 값을 읽는다. 이 값이 문서 상세 팝업 URL이며 아래와 같은 형태다:

```
https://a10.donghoon.com/#/popup?MicroModuleCode=eap&docAuth=0&docID={docID}&formId={formId}&pageCode=UBA1100&callComp=UBAP002&popupUUID={uuid}
```

`docID`와 `formId` 값을 기록해둔다. (지출_구매 기안서(지출) 양식은 formId=1174였다. 대금 지급 요청 등 다른 양식은 문서마다 확인해서 사용 — 하드코딩하지 말고 항상 직접 열어서 확인한 값을 쓴다.) 원본 URL 문자열 자체는 세션 토큰과 유사하게 보여 안전 필터에 걸릴 수 있으니, JS 안에서 정규식으로 docID/formId 값만 추출해서 읽는다(전체 URL을 그대로 출력하지 않는다).

이 URL로 `navigate` 하면(직접 URL 이동은 팝업 차단에 걸리지 않는다) 문서 상세를 같은 탭에서 볼 수 있다.

**대안: window.open 가로채기도 안 통할 때 (React Fiber로 docID 직접 읽기, 2026-08-03 확인)**: 문서 행의 아이콘이 "새창열기"가 아니라 "고정"/"내보내기" 등 다른 기능일 수도 있고, window.open 후킹으로도 URL을 못 잡는 경우가 있다. 이럴 때는 문서 행 DOM 요소에서 React의 내부 Fiber 트리를 타고 올라가 숨겨진 `id`(docID) prop을 직접 읽을 수 있다:

```js
const el = document.querySelector('선택자로 찾은 문서 행 엘리먼트');
const fiberKey = Object.keys(el).find(k => k.startsWith('__reactInternalInstance$') || k.startsWith('__reactFiber$'));
let fiber = el[fiberKey];
while (fiber) {
  if (fiber.memoizedProps && fiber.memoizedProps.id) { /* fiber.memoizedProps.id 가 docID (예: "readchk_1005988") */ break; }
  fiber = fiber.return;
}
```

이렇게 얻은 docID를 위 팝업 URL 패턴에 바로 넣어 `navigate`하면 클릭 자체를 시도할 필요 없이 문서 상세로 들어갈 수 있다. window.open 후킹이 실패하면 이 방법으로 바로 넘어갈 것.

### 3) "기안작성"(복사해서 새로 쓰기) 화면 열기

문서 상세 화면 상단 툴바에는 아이콘 6개가 있고, **왼쪽에서 3번째(연필 아이콘)** 가 "기안작성"이다. 이것도 클릭 시 팝업이 막힐 수 있으므로, 2)에서 확인한 `docID`, `formId`를 이용해 아래 URL 패턴으로 바로 `navigate` 한다 (popupUUID는 임의로 새 UUID를 만들어 붙이면 된다):

```
https://a10.donghoon.com/#/popup?MicroModuleCode=eap&docID={docID}&draftTp=40&formId={formId}&reDraft=Y&callComp=UBAP001&popupUUID={새로_생성한_uuid}
```

이 화면이 열리면 기존 문서 내용이 그대로 복사된 편집 가능한 기안 작성 폼이 나온다. 상단에 **미리보기 / 보관 / 상신** 버튼이 보인다.

### 4) 내용 채우기

- **제목** 입력창: 위 "문서 템플릿"에서 정한 제목으로 전체 교체
- **본문** (리치텍스트 에디터 영역): 기존 내용을 전체 선택해 지우고 처음부터 다시 쓰지 말 것 — 원본 문서의 색상·폰트·표 서식(헤더 음영, 총계 행 색상 등)이 그대로 사라진다. **반드시 복사된 기존 문서의 문단·표를 그대로 두고, 각 줄/셀 안의 텍스트만 클릭해서 교체하는 방식으로 편집한다.** 표는 원본 표의 행을 복제(표 메뉴의 "줄/칸 추가하기")해서 필요한 행 수를 맞추고 셀 내용만 채운다. 표를 완전히 새로 만들어야 하는 경우에만 표 메뉴의 "표 만들기"를 쓴다.
- **줄 단위 편집 시 주의사항 (서식 깨짐 방지, 매우 중요)**: 이 에디터는 문단이 짧으면 다음 문단이 같은 줄에 붙어 보이는 경우가 있고, 삼중 클릭(triple-click)이 항상 문단 하나만 정확히 선택하지 않고 인접한 다음 문단까지 함께 선택/삭제해버리는 경우가 있다. 그래서:
  1. 한 줄을 다 지우고 다시 쓴 뒤에는 **반드시 스크린샷으로 확인**해서 다음 줄 내용이 같은 줄에 뒤섞이지 않았는지, 반대로 다음 줄이 통째로 사라지지 않았는지 확인한다.
  2. 이상하게 합쳐진 게 보이면, 정확한 지점을 클릭 → `Home`(줄 시작) → `Shift+End`(줄 끝까지 선택, 필요하면 `Shift+Down` `Shift+End`를 더해 여러 줄 선택) 방식으로 원하는 범위만 정확히 선택한 뒤 지우고 다시 입력한다. 좌표만 보고 삼중 클릭으로 재시도하지 않는다. `Home`+`Shift+Down`만으로는 첫 줄이 아니라 두 번째 시각적 줄부터 선택되는 경우가 있었으니, 의심되면 `Home`+`Shift+Down`+`Shift+Home`으로 한 번 더 줄 시작 위치를 보정한 뒤 삭제한다.
  3. 최종 저장(보관) 전에 전체 본문을 처음부터 끝까지 스크롤하며 스크린샷으로 한 번 더 훑어, 줄바꿈 위치·띄어쓰기·들여쓰기가 원본 서식과 어긋난 곳이 없는지 확인한다.
  4. 표(예: "7. 예산항목" 표)를 완전히 삭제해야 할 때 제목+셀을 선택해 Delete를 눌러도 빈 표 껍데기(1행짜리 빈 테이블)가 남는 경우가 있다 — 이때는 빈 표 안을 클릭한 뒤 `Ctrl+Backspace`를 눌러 표 구조 자체를 제거한다.
- **수신및참조**: 복사된 기존 값(기획감사실, 경영지원팀(포천/창녕), 재경팀 등)을 그대로 둔다. 특별히 다른 사업장이면 사용자에게 확인 후 조정.
- **품의번호**는 "기본채번"으로 자동 채번되므로 건드리지 않는다.
- **참조문서(하단 "참조문서" 영역)**: 새 구매요청서를 추가하는 것은 문제없이 된다. 그러나 **복사해온 원본 문서에 이미 걸려있던 기존 참조문서(예: 다른 건의 구매요청서)를 지우는 작업은 UI 자동화로 여러 방법(체크박스 토글, 전체선택 체크박스, 더블클릭, "이동" 드래그, 목록 재검색 후 토글)을 시도해도 반영되지 않았던 사례가 있다(2026-08-03).** HTML5 드래그앤드롭이 합성 마우스 이벤트로 트리거되지 않는 등의 이유로 추정된다. 이 문제를 만나면 무리하게 반복 시도하지 말고, 완료 보고 시 "참조문서에 이전 건이 남아있으니 상신 전 직접 정리해달라"고 사용자에게 명확히 알린다 — 실제로 사용자가 그룹웨어 화면에서 직접 조작하면 제거는 가능하다(자동화만 안 되는 것). 더 나은 자동화 방법을 발견하면 이 항목을 업데이트할 것.

### 4-1) 결재라인 규칙 (금액 및 부서/사업장에 따라 다름)

지출_구매 기안의 **결재(전자결재선)는 3번 금액(총 견적 금액) 기준으로 다르게 구성한다.** 복사해온 문서의 결재선이 아래 규칙과 다르면 반드시 맞게 고친다.

- **총 금액이 100만원 미만**: 결재라인을 **김태훈 대표이사까지만** 넣는다 (담당 이관현 → 차장 유환익 → 전무 김광섭 → 대표이사 김태훈). 이때 **"전결" 체크박스를 반드시 체크**한다.
- **총 금액이 100만원 이상**: 결재라인에 **김남연 대표이사까지 전부** 넣는다 (담당 이관현 → 차장 유환익 → 전무 김광섭 → 대표이사 김태훈 → 대표이사 김남연). 이때도 **"전결" 체크박스를 반드시 체크**한다.
- 결재선 표에는 "대표이사" 칸이 두 개 있는데(김태훈, 김남연 각각 별도 칸) 100만원 미만이면 김남연 칸은 비워두고(결재선에서 제외), 100만원 이상이면 두 칸 모두 채운다.
- **"전결" 체크박스 위치**: 결재선 표에서 마지막 결재자(100만원 미만이면 김태훈 대표이사, 100만원 이상이면 김남연 대표이사) 칸을 클릭하면 뜨는 **팝업 안에** 전결 체크박스가 있다. 그 팝업에서 체크박스를 체크해야 한다.
- **"합의" 줄 (부장 조이형)은 포천 코스관리팀 관련 구매 건 전용이다.** 포천 코스관리팀 건을 복사해서 다른 부서/사업장(예: 본사) 건을 만들면 이 합의 줄이 그대로 딸려온다 — **본사/일반 부서 지출_구매 기안에서는 이 합의 줄을 제거한다.** 반대로 포천 코스관리팀 관련 건이면 유지한다. (2026-08-03 본사 PC/모니터 구매 건에서 확인 및 수정된 규칙.)

### 4-2) 표(3.금액 등) 안 행 삭제/편집 시 에디터 조작법 (2026-08-03 확인)

- **행 삭제**: 지우려는 행의 셀 위에서 우클릭 → 컨텍스트 메뉴의 "삭제" 위에 **클릭이 아니라 반드시 마우스 오버(hover)** 해야 하위 메뉴("칸 지우기"/"줄 지우기"/"표 지우기")가 펼쳐진다. "삭제"를 그냥 클릭하면 하위 메뉴가 열리지 않고 메뉴만 닫혀버린다. 하위 메뉴가 뜨면 "줄 지우기"(단축키 Ctrl+Backspace)를 클릭한다.
- **행 삽입 시 셀 병합 상속 문제**: "소계"처럼 여러 칸이 하나로 병합된 행을 기준으로 "아래쪽에 줄 추가하기"를 하면, 새로 생긴 행도 그 병합 구조를 그대로 물려받는다(예: 구분+제품명+품목 3칸이 합쳐진 상태로 생성됨). 그 상태로 텍스트를 치면 여러 칸 내용이 한 칸에 합쳐져 들어간다 — 이 경우 우클릭 메뉴의 "셀 나누기"(Ctrl+Alt+S)에서 "칸 수"를 원래 컬럼 수(보통 3)로 지정해 원상복구한 뒤 다시 채운다.
- **숫자/텍스트 수정 후에는 반드시 zoom 스크린샷으로 셀 단위 확인**: 더블클릭으로 단어를 선택할 때 의도한 글자보다 더 넓게(예: 복합 날짜 토큰 전체) 선택되는 경우가 있고, 트리플클릭으로 문단을 선택할 때 커서 위치가 한 줄 밀려서 엉뚱한 행이 지워지는 경우가 있었다. 셀 하나를 고치고 나면 바로 옆/아래 셀 내용이 의도치 않게 같이 바뀌지 않았는지 확인 후 다음 셀로 넘어간다.
- **표 안 숫자를 고치고 나면 그 표와 연결된 다른 곳(예: 헤더 줄의 "총 X원", "8.예산항목"의 "당회 금액")도 함께 갱신해야 하는지 항상 다시 확인한다** — 위 "1-2. 업장 소모품 구매" 절에서 헤더 총액을 놓쳤던 사례 참고.

### 5) 저장 (반드시 "보관"만)

내용 작성 후 화면 우측 상단의 **"보관"** 버튼을 클릭한다. **"상신" 버튼은 절대 클릭하지 않는다.** 저장되면 결재수신함이 아니라 `상신/보관함 > 임시보관문서`로 들어간다.

### 6) 완료 보고

작업이 끝나면 사용자에게: 어떤 폴더/파일 기준으로 작성했는지, 채운 금액·업체 요약, 그룹웨어 임시보관문서함에 저장됐다는 것, 최종 확인 후 직접 상신해야 한다는 것을 함께 보고한다. 참조문서 정리처럼 자동화로 처리하지 못한 부분이 있으면 반드시 함께 알린다.

## 발주서 자동완성 (2단계)

지출_구매 기안이 "보관"까지 완료된 뒤, 같은 폴더에 **발주서 양식(빈 xlsx, 업체 지정 템플릿)** 파일이 새로 추가되면:

1. 그 폴더의 견적서 내용과, 기안에서 선정한 업체/품목/수량/단가 정보를 사용해 발주서를 채운다.
2. 구체적인 발주서 채우기 방식은 `hillmaru-quote-to-po` 스킬의 로직(품명/규격/단위/수량/단가를 발주서 품목표에 옮기는 방식)을 그대로 따른다.
3. 완성된 발주서는 같은 폴더에 저장하고 사용자에게 보고한다.
