# 힐마루 견적관리 시스템 운영

이쿠키(구매·데이터 담당)가 사용하는 스킬입니다. 자체 개발한 Node.js 견적관리 웹앱(https://hillmaru-quote-system.onrender.com)에서 업체·사업장·카테고리 등록부터 견적요청 생성, 업체 견적 비교·선정, 발주서 다운로드까지 구매 프로세스 전반을 대신 수행합니다.

## 절대 규칙 (안전)

- 로그인 아이디/비밀번호를 스킬이 직접 입력하지 않는다. Claude in Chrome이 이미 로그인된 세션을 사용한다고 가정하고, 로그인이 안 되어 있으면 사용자에게 직접 로그인을 요청한다.
- 견적요청을 생성하면 배정된 업체에게 실제 알림 메일이 나갈 수 있다(이메일 발송이 설정된 경우). 사용자가 "견적요청 만들어줘/생성해줘"처럼 명시적으로 요청했을 때만 실제로 생성 버튼을 클릭한다. 초안만 검토하고 싶은 건지 모호하면 먼저 물어본다.
- 업체 최종 선정("이 업체로 선정"), 업체/계정 활성화·비활성화, 비밀번호 변경처럼 되돌리기 번거로운 동작은 실행 전 대상과 내용을 사용자에게 확인받는다.
- 관리자 기본 계정(admin) 비밀번호는 이 스킬로 조회하거나 변경하지 않는다.
- 엑셀 일괄 등록/제출 기능을 쓸 때는 반드시 해당 화면의 "양식 다운로드" 링크로 받은 빈 템플릿을 채워서 올린다. 임의로 만든 엑셀 파일을 올리지 않는다(컬럼 순서가 맞지 않으면 데이터가 잘못 들어간다).

## 접속 정보

- URL: https://hillmaru-quote-system.onrender.com
- 관리자 로그인: `/login?role=admin`
- 업체 로그인: `/login?role=vendor`
- Render 무료 티어라 일정 시간 미접속 시 슬립 상태가 되어 첫 요청 응답이 최대 50초 정도 걸릴 수 있다. 첫 로딩이 느리면 잠시 기다렸다가 새로고침한다.

## 주요 화면

| 기능 | 경로 |
|---|---|
| 관리자 대시보드 | `/admin` |
| 업체 관리(등록/수정, 엑셀 일괄 등록) | `/admin/vendors` (양식: `/admin/vendors/template`) |
| 사업장 관리 | `/admin/sites` (양식: `/admin/sites/template`) |
| 업체 카테고리 관리 | `/admin/categories` (양식: `/admin/categories/template`) |
| 새 견적요청 작성 | `/admin/quote-requests/new` (품목 양식: `/admin/quote-requests/items-template`) |
| 견적요청 상세(비교표/선정/발주서) | `/admin/quote-requests/:id` |
| 계정설정 | `/admin/account` 또는 `/vendor/account` |

## 절차 — 견적요청 생성

1. 사용자에게 사업장, 품목(품목명/규격/수량/단위), 제출 마감일, 배정할 업체(또는 카테고리), 담당자명·담당자이메일을 확인한다. 담당자이메일을 넣어두면 업체가 견적을 제출했을 때 그 주소로 알림이 간다.
2. `/admin/quote-requests/new`로 이동해 폼을 채운다. 품목이 많으면 화면의 "양식 다운로드" 링크로 빈 엑셀을 받아 채운 뒤 품목 업로드란(`items_excel`)에 올리는 방식을 우선 제안한다.
3. 카테고리별 업체 목록에서 배정 체크박스를 사용자가 지정한 대로 체크한다.
4. "견적요청 생성"을 클릭하기 전, 사업장/품목/배정 업체/담당자이메일을 사용자에게 다시 요약해 확인받는다 — 클릭하면 실제 업체에게 통지가 갈 수 있는 동작이다.

## 절차 — 업체/사업장/카테고리 일괄 등록

1. 등록할 목록(이름, 담당자, 연락처, 로그인아이디 등)을 사용자와 정리한다.
2. 해당 화면(`/admin/vendors`, `/admin/sites`, `/admin/categories`)에서 "양식 다운로드"로 빈 엑셀을 받는다.
3. 로컬에서 내용을 채운 뒤(필요하면 Bash로 openpyxl 등을 써서 채워도 된다) 업로드 폼에 올려 일괄 등록한다. 몇 건 안 되면 화면의 수동 등록 폼을 바로 써도 된다.
4. 이미 존재하는 로그인아이디/이름은 건너뛰어질 수 있다는 점을 결과 메시지로 확인하고 사용자에게 알린다.

## 절차 — 견적 비교 및 최종 선정

1. `/admin/quote-requests/:id`에서 품목별 제출 견적 비교표를 확인한다.
2. 최저가가 아닌 업체를 선정하려는 경우 선정 사유를 입력해야 하므로, 어떤 근거로 선정할지 사용자에게 먼저 물어본다.
3. "이 업체로 선정"은 되돌리기 번거로운 동작이므로, 어느 품목·업체를 선정할지 사용자가 명확히 확인해준 뒤에만 클릭한다.

## 절차 — 발주서 다운로드

- 품목이 하나 이상 선정된 뒤 상세 페이지의 발주서 생성 영역에서 구매담당/발주일자 등을 지정하고 "발주서 다운로드"를 클릭하면 xlsx 파일이 내려받아진다.

## 참고

- 화면은 서버에서 렌더링되는 일반 HTML 폼이라 Claude in Chrome의 navigate/computer/find로 조작 가능하다.
- 보안상 로그인 화면에 기본 계정 힌트가 노출되지 않는다. 최초 접속 정보는 사용자에게 직접 확인한다.
- 이메일(SMTP) 발송 설정 여부는 상황에 따라 다르므로, 발송 여부를 단정하지 말고 "설정되어 있다면 알림 메일이 나갈 수 있다"는 전제로 신중하게 동작한다.
